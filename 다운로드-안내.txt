Ian 번역 작업실 — 다운로드 안내

GitHub 저장소에는 프로젝트 소스가 들어 있습니다. 실행 전에 아래 명령으로 빌드하세요.
별도 실행 패키지에 frontend/dist가 포함돼 있다면 빌드를 생략할 수 있습니다.

소스를 다시 빌드하려면 Node.js 22.12 이상에서 프로젝트 폴더를 열고 실행하세요:
  npm ci
  npm --prefix frontend ci
  npm run build

로컬 실행판은 Ollama 모델로 자동 번역할 수 있습니다. Ollama를 설치하고 모델을
내려받은 뒤 http://127.0.0.1:4173 의 작품별 모델 연결에서 로컬 Ollama를 선택하세요.
로컬 모델에는 API 키가 필요하지 않습니다. 현재 UI에서는 로컬 Ollama를 사용합니다.
