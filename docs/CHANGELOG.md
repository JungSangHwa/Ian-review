## 첨부 원본에서 변경한 내용

원본의 홈·검수·평가 플레이스홀더와 연결되지 않은 API 호출 틀을 실제 로컬 데이터 흐름으로 교체했습니다. 외부 백엔드가 없다는 사실을 숨기지 않고 개인 로컬 모드로 범위를 고정했습니다.

문서 등록/가져오기, 검색/필터/정렬, 문단 편집과 저장, 변경 이력, 수동 이슈, 규칙 검사, 수정안 적용·무시·해결, 문단 확인과 완료/재개를 구현했습니다. A/B 후보 등록과 무작위 순서 보관, 임시 저장과 제출, 제출 후 이름 공개, 점수 및 선호도 내보내기를 연결했습니다.

언어 쌍별 용어집과 중복 검증, 저장소 실제 상태에 기반한 대시보드, JSON 백업/엄격한 검증/전체 복원/복구 사본을 추가했습니다. 미저장 이동 경고, 구 버전 수정안 차단, 오래된 탭 리비전 충돌 방지, 저장 실패 입력 보존, 읽기 실패 안내를 구현했습니다.

데스크톱/모바일 레이아웃, 키보드 단축키, 공통 다이얼로그·빈 상태·알림·오류 화면과 기능 범위를 설명하는 도움말을 추가했습니다. 모바일 표의 스크린리더 전용 레이블이 페이지 전체의 가로 넘침을 만드는 문제를 수정했습니다.

Windows 전용 node_modules를 배포물에서 제외하고, 실제 검증한 production 빌드와 의존성 설치 없이 실행하는 로컬 Node 서버·OS별 진입 스크립트를 포함했습니다. 소스 수정용 lockfile, 네이티브 바이너리 없는 기본 빌드 경로, Vite 대체 경로, 35개 단위 테스트와 15개 브라우저 회귀 테스트를 제공합니다.
