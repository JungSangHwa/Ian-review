IAN — 웹소설·자막 번역 검수 작업실
==================================

GitHub 소스에는 빌드 산출물이 포함되지 않습니다. Node.js 22.12 이상에서 먼저 실행하세요:
  npm --prefix frontend ci
  npm run build

1. Ollama를 설치·실행하고 채팅 모델을 내려받습니다. 예: ollama pull qwen3:8b
2. node start.mjs를 실행하고 http://127.0.0.1:4173 을 엽니다.
   Windows: START_WINDOWS.bat / macOS·Linux: sh START_MAC_LINUX.sh
3. 사이드바나 홈에서 프로젝트를 만들고 원고·자막을 등록합니다.
4. 작품의 모델 연결에서 설치된 로컬 Ollama 모델을 선택·확인·저장합니다. API 키는 필요하지 않습니다.
5. 검수 화면에서 모델 번역을 시작합니다. 작품 용어집의 남은 원문 검증이 먼저 실행됩니다.
   페이지를 옮겨도 사이드바에서 작업 단계와 저장 완료 수를 확인하고 일시 중지할 수 있습니다.
6. 모델이 용어집을 생성·검증하고 기준 문서에 자동 반영합니다. 번역문은 의미와 말투도 확인하세요.
7. TXT·CSV 또는 원래 SRT·VTT 형식으로 결과를 내보내고 전체 JSON 백업을 받습니다.

기본 예제: 웹소설 2회차 12문단, 자막 8구간, 용어 8개.
문서는 현재 브라우저·프로필·주소의 IndexedDB에 저장됩니다. 다른 기기로 옮길 때는 JSON 백업을 복원하세요. 복원은 현재 작업 공간 전체를 교체합니다.
