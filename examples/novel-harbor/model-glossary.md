# 안개항의 마지막 종 · 모델 용어집

문학적 미스터리 판타지 소설. 지문은 자연스러운 한국어 ~다 문체. 은유의 뜻, 행위 주체, 부정, 시간 순서와 단서를 보존한다. 대사는 한국어 소설처럼 자연스럽게 쓰되 관계를 지어내지 않는다. Nara는 성인 수리공, Jun은 소년이며 Nara와 친하다. Jun은 Nara에게 존댓말, Nara는 Jun에게 반말. Nara와 노인 Elias는 처음 만난 사이로 서로 존댓말을 쓴다. 인물 이름과 별명·직함은 구별한다. 고유명사의 한국어 표기는 모델이 원문 근거로 정하고 이후 모든 회차에 같은 기준을 적용한다. 숫자, 소유 관계, 생사와 선택을 바꾸지 않는다. 요약하거나 설명을 덧붙이지 않는다.
